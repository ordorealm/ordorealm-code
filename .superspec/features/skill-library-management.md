# F01: 技能库管理

> 功能详情文档
> 版本：1.0.0
> 创建日期：2026-05-24

---

## 1. 功能概述

在设置界面管理技能库列表，支持添加、编辑、删除、导出技能库。

---

## 2. 用户故事

```
作为一名开发者，
我想要管理我的专家技能库，
以便在不同项目中快速切换使用不同的技能配置。
```

### 4.2 添加技能库 (F01-2)

**用户操作**：
1. 点击"添加技能库"按钮
2. 拖拽或点击上传 zip 文件
3. 系统验证 zip 文件结构
4. 填写名称、说明、选择 Agent 类型
5. 点击"保存"

**系统行为**：
1. 接收 zip 文件路径（通过 Electron dialog）
2. 调用 `skill-library:validate` 验证结构
3. 验证通过后，复制 zip 到用户数据目录
4. 创建 library.json 元数据文件
5. 返回新技能库信息

**验证规则**：

```typescript
async function validateSkillLibrary(zipPath: string): Promise<ValidateResult> {
  // 1. 检查文件大小
  const stats = fs.statSync(zipPath);
  if (stats.size > 100 * 1024 * 1024) {
    return { valid: false, error: '文件大小超过 100MB 限制' };
  }
  
  // 2. 解析 zip 文件
  const zip = new AdmZip(zipPath);
  const entries = zip.getEntries();
  
  // 3. 检查主配置文件
  const mainFiles = ['CLAUDE.md', 'AGENTS.md', 'opencode.md'];
  const hasMainFile = entries.some(e => 
    mainFiles.some(mf => e.entryName.endsWith(mf))
  );
  
  if (!hasMainFile) {
    return { valid: false, error: '缺少主配置文件（CLAUDE.md、AGENTS.md 或 opencode.md）' };
  }
  
  return { valid: true };
}
```

### 4.4 删除技能库 (F01-4)

**用户操作**：
1. 点击技能库卡片的"删除"按钮
2. 确认删除操作
3. 技能库从列表中移除

**系统行为**：
- 调用 `skill-library:delete` 删除目录
- 删除 library.json 和 archive.zip

### 4.5 导出技能库 (F01-5)

**用户操作**：
1. 点击技能库卡片的"下载"按钮
2. 系统打开保存对话框
3. 用户选择保存位置
4. 文件保存成功

**系统行为**：
- 调用 `skill-library:download` 获取 zip 路径
- 复制 zip 到用户选择的位置

## 5. IPC 接口

### 5.1 skill-library:list

```typescript
// 渲染进程调用
const libraries = await window.api.skillLibrary.list();
// 返回: SkillLibrary[]
```

### 5.2 skill-library:add

```typescript
// 渲染进程调用
const library = await window.api.skillLibrary.add({
  zipPath: '/path/to/archive.zip',
  name: 'Superspec 全流程',
  description: '自动化从需求到交付的开发全流程',
  agentType: 'claude-code'
});
// 返回: SkillLibrary
```

### 5.3 skill-library:update

```typescript
// 渲染进程调用
await window.api.skillLibrary.update({
  id: 'uuid-xxx',
  name: '新名称',
  description: '新说明'
});
```

### 5.4 skill-library:delete

```typescript
// 渲染进程调用
await window.api.skillLibrary.delete({ id: 'uuid-xxx' });
```

### 5.5 skill-library:download

```typescript
// 渲染进程调用
const result = await window.api.skillLibrary.download({ id: 'uuid-xxx' });
// 返回: { path: string }
// 然后通过 dialog 让用户选择保存位置
```

### 5.6 skill-library:validate

```typescript
// 渲染进程调用
const result = await window.api.skillLibrary.validate({ 
  zipPath: '/path/to/archive.zip' 
});
// 返回: { valid: boolean, error?: string }
```

## 6. 错误处理

| 错误场景 | 错误信息 | 用户操作 |
|---------|---------|---------|
| zip 文件损坏 | 无法解压文件，请检查 zip 格式是否正确 | 重新打包上传 |
| 缺少主配置文件 | 缺少主配置文件（CLAUDE.md、AGENTS.md 或 opencode.md） | 检查 zip 内容 |
| 文件过大 | 文件大小超过 100MB 限制 | 压缩或精简内容 |
| 磁盘空间不足 | 磁盘空间不足，无法保存技能库 | 清理磁盘空间 |
| 读取失败 | 无法读取文件，请检查文件权限 | 检查文件权限 |
